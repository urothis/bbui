# Properties editor design reference

The object page in [BUI's component demo](https://github.com/ppmpreetham/BUI/blob/e981a6caea300629f3f1cad846d08785c5cde649/examples/components_demo.py#L35) is the source for this example's composition. It uses an `IDSelector`, expanded Transform and Visibility panels, and a collapsed Viewport Display panel. Transform contains two three-axis `VectorField` groups followed by 40/60 split property rows for Scale and Mode. Visibility contains a joined three-toggle row, a two-column checkbox grid, and nested Mask and Motion Blur panels. The application frame uses `SideTabs`, a menu bar, a progress bar, and a status line.

The [component containers](https://github.com/ppmpreetham/BUI/blob/e981a6caea300629f3f1cad846d08785c5cde649/bindings/python/bui/components/containers.py#L46) define the split and grid structure. The [ID selector template](https://github.com/ppmpreetham/BUI/blob/e981a6caea300629f3f1cad846d08785c5cde649/bindings/python/bui/components/templates.py#L18) combines a browse dropdown, editable name, fake-user toggle, duplicate action, and unlink action. In the native [panel layout](https://github.com/ppmpreetham/BUI/blob/e981a6caea300629f3f1cad846d08785c5cde649/kit/intern/kit_widgets.c#L450), ordinary controls get an inset while nested panels occupy the panel body's full width.

Our Rust example mirrors that hierarchy with Bevy widgets. Its compact numeric rows, filled slider, bordered dropdown, flat menus, and segmented toggles are reusable paint roles. The Visibility panel places nested panels at its full width, while ordinary controls keep an eight-pixel inset. Top-level Object panels draw the muted drag grip from [BUI's panel header](https://github.com/ppmpreetham/BUI/blob/e981a6caea300629f3f1cad846d08785c5cde649/kit/intern/kit_widgets.c#L758) and belong to a persistent reorderable group; nested Mask and Motion Blur panels omit it. The six side tabs switch pages; Modifiers uses a ramp and curve editor, Material uses preview tiles and an HSV editor, Outliner uses a tree and list, and Geometry Nodes uses a linked graph.

The reference uses Blender's own icon set and font metrics. Our sidebar icons are purpose-drawn vector symbols and text is shaped with Bevy's font pipeline, so icon silhouettes and a few glyph positions still differ. The checked-in [default capture](examples/properties_editor.png) and [page captures](README.md) show the actual renderer output. Capture again with `cargo build -p bui --example properties_editor --locked` and `DISPLAY=:99 python3 scripts/capture_examples.py properties_editor` (use an available X11 display).
