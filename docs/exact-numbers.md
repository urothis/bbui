# Exact integer controls

Use `NumericField::integer(i64)` or `NumericField::unsigned(u64)` for full-width values. The declarative equivalents are `WidgetNode::exact_i64(label, value)` and `WidgetNode::exact_u64(label, value)`. Read `typed_value()` and write with `set_typed_value(NumericValue::Integer(...))` or `NumericValue::Unsigned(...)`. Numeric state is private: `value_projection()`, `bounds_projection()`, and `step_projection()` supply layout values, while the typed getters and validated setters preserve full-width data. A projection can round above `2^53` and is never the source of truth for integer data.

Typed editing accepts checked integer arithmetic with parentheses, unary signs, `+`, `-`, `*`, `/`, and `x` for the current value. `NumericExpressionVariables` now holds `HashMap<String, NumericValue>` so named signed and unsigned variables can also retain full width; float variables remain available. Comparisons, conditionals, remainder, powers, and integer functions use the shared expression grammar. Expressions requiring fractional or transcendental math evaluate the complete float expression and round only its final result when the current integer, named variables, and literals are safe as `f64`; full-width expressions reject that float path rather than silently round. Invalid input stays in the edit buffer with an error. Keyboard stepping, scrubbing, bounded slider movement, clipboard text, action events, undo/redo, and accessibility values use the typed integer. Bounds, defaults, and steps use validated setters. `NumericField::evaluate_input` and `commit_edit` now accept the typed variable map.

The legacy `NumericField::new` constructor accepts integer values and bounds only within the exact `f64` range. Unsigned fields reject negative input, and integer steps must be positive, whole, and exactly representable. Use the typed constructors and `set_typed_bounds` for values outside that range.

When updating existing hosts, wrap former `f64` expression variables in `NumericValue::Float` and use `NumericValue::Integer` or `NumericValue::Unsigned` for full-width inputs. Replace direct reads of the former public numeric fields with the projection or typed getters; replace direct writes with `set_value`, `set_typed_value`, `set_bounds`, `set_typed_bounds`, `set_default`, `set_typed_default`, `set_step`, or `set_typed_step`.
