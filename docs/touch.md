# Touch gestures

BBUI routes the first touch through its normal pointer path. Controls keep their existing tap, press, and drag behavior. When a second touch begins inside the same gesture surface, BBUI cancels the pending pointer press and starts a two-finger gesture on that surface. Lifting either finger ends the gesture.

`UiScroll`, `Canvas`, and `NodeGraph` opt in automatically. A scroll surface pans in both axes; Canvas and NodeGraph pan around the moving center and scale around the pinch center. Nested scroll surfaces use the deepest common gesture surface for both fingers. A custom control can opt in by inserting `UiGestureSurface` on the entity that should receive `UiRoutedEvent::SurfaceGesture`.

The routed event includes `Started`, `Updated`, `Ended`, and `Cancelled` phases, logical center coordinates, logical delta, and a scale ratio. A custom surface can use any subset of those values. Gestures are scoped to the window and cancel when the window loses focus. If a surface becomes unavailable during a gesture, the next touch event cancels it.

On macOS, BBUI also samples precise two-finger scroll and pinch events through an AppKit local monitor. The bridge keeps AppKit's window-local position, incremental deltas, gesture phases, and scroll momentum, converts them to BBUI logical coordinates, and routes a phased stream to the surface where it began. Command or Control plus precise scroll produces a position-centered scale change; a pinch uses AppKit's incremental `1 + magnification` scale. Precise scrolling over a control without a gesture surface still arrives as a pixel wheel event. Each sample carries its AppKit window number, and the bridge accepts only samples from the native primary window; other platforms have no Apple dependency.

The same macOS monitor also observes native mouse-up and drag positions. If Bevy misses a release, BBUI restores Bevy's button state, publishes the recovered window event, and delivers it to the active UI pointer capture; a release that coincides with movement is deferred one frame so the last drag update is retained. Native drag recovery respects world-input targets. If the monitor cannot install, BBUI consults AppKit's pressed-button snapshot after a brief stationary period. Losing window focus releases held buttons.

Run `cargo run -p bbui --example touch_gestures` on a touch device. The [before](visuals/examples/touch-gestures-start-dark.png), [after dark](visuals/examples/touch-gestures-dark.png), and [after light](visuals/examples/touch-gestures-light.png) captures come from the runnable example; the capture test injects two touches and verifies the canvas zoom changes.
